# Wordless Joker face

This first portrait version has been superseded by the [two distinct monochrome Joker icons](JOKER-ICONS.md). The files and prompt below are retained as provenance for the original attempt; the game now uses the two icon assets.

Generated with the built-in imagegen tool on 2026-10-21 for AssholeGPT. No reference image was supplied. This fictional illustration is included under the project GPL-3.0-only license.

- Source: `assets/joker-face-source.png`.
- Runtime: `public/images/joker-face.jpg`, 120 x 160 pixels, opaque RGB baseline JPEG.
- Reproduce packaging: `python scripts/prepare-joker.py` (Pillow required for development only).
- This first version used one wordless jester portrait for both cards, distinguished by border and accessible name. The active version now uses separate drawings.

## Final generation prompt

Use case: illustration-story. Asset type: a single Joker playing-card FACE image for a small legacy computer card game. Portrait 1024x1536. A classic friendly mischievous jester's face and shoulders filling almost the entire card, large expressive face, three-point floppy red-and-black jester cap with round brass bells, diamond-pattern collar, vintage woodcut / traditional printed playing-card illustration with strong black outlines, simple bold shapes and high contrast that remain recognizable when reduced to 34x46 pixels. Warm ivory plain background, red, charcoal black, antique gold, cream. Flat front view, centered, upright, face visible. Entire image is the face of the playing card, no table or surrounding objects, no perspective, no external drop shadow, no rounded corners. Absolutely NO words, NO letters, NO numbers, NO typography, NO labels, NO watermark. No sinister horror or clown makeup. Opaque image.
